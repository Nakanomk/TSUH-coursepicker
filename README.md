# 通用选课助手 v2

由图形学脚本重构。

**这里的“通用”指：在原选课站点、原有“先排后选”流程中，配置不同课程、教师和学期。不是任意学校、任意选课类别的通用工具。**

安装使用 `dist/hust-course-picker.user.js`。维护修改 `src/`，不要直接修改生成的 dist 文件。

## 安装与使用

1. 先停用旧的图形学脚本，并刷新所有已经打开的选课页面。旧脚本的锁和待确认记录受到兼容保护，但不建议两个版本同时启用。
2. 在你使用的用户脚本管理器中新建脚本，用 `dist/hust-course-picker.user.js` 的完整内容替换编辑器内容，保存；进入原选课页面。
3. 在右下角填写学期编号、课程完整名称和教师全名。可以添加多门不同课程。首次学期留空，必须自行核对；`20261` 只是旧脚本所用编号，程序不根据日期猜测。
4. 先点击“只读检查”。唯一匹配时显示课堂号；多个匹配时，展开候选课堂，核对学校页面中的上课时间、校区等信息，再点击“限定为这个课堂”。这个按钮只填入编号，不提交，也不改变教师姓名。再次只读检查确认。
5. 点击“开始自动选课”，确认目标与学期后，程序才会自动循环检查和提交。所有目标确认已选后停止。

“保存配置”和“只读检查”不会开启后台自动选课。配置保存到本站 localStorage；刷新/重新打开页面后不会自动重启，必须再次点击启动。用户脚本本身不需要 Node.js、npm、Python，也没有远程运行时依赖。

教师必须填写，不提供留空自动任选教师；同一门课程不要用两个教师添加成两条任务。课堂存在多名教师时，保留原脚本按 XM / KTFZR.XM 拆分并合并的规则，指定姓名必须命中其中一个完整姓名。不使用模糊包含、正则或相似度匹配。

## 禁选名单

为避免在重构时无声删除原先的保护，默认保留：

- 课程名称或方案名称包含 `接口技术`。
- 课程号为 `w121673`，不区分大小写。

它们已移到“高级设置”的两个可编辑字段，不再散落在业务代码中。确实要选该课时，需要同时检查并删除相关关键词和课程号限制。其他默认目标为空，没有固定必须选的课程。

## 行为与安全边界

### 查询、提交和确认是不同阶段

程序严格区分：发现候选、准备提交、服务器接受、实际课堂状态确认。

提交前先同步写入持久化记录，再发送请求。若请求超时、网络中断、返回无法解析的内容，记录不清除，也不会自动重发；后续只能查询原课堂是否已选。收到 `code=0` 同样不立即宣称成功，而是查询课堂状态。保留原脚本约定：`TYPE=1/2` 被视为已选，`TYPE=0` 为未选；合法的非零业务 code 被视为明确拒绝。

**以上接口语义来自原脚本，不是本次独立验证过的教务系统文档。** 其他选课类别或学校变更接口语义时，需要调整适配层。

待确认记录保存原始课程、教师、学期和课堂快照。即使新配置改变，也先检查旧提交，不会把记录解释成新目标。旧版 `hust-graphics-20261-v1:pending` 记录也会读取核对；只兼容本次上传的这一旧版本，不猜测其他历史脚本的教师或参数。

查不到课堂或课堂仍显示未选，不足以证明旧提交不会稍后生效，所以不会自动清除记录。需要人工解除时，先暂停并等待当前请求完成，在学校页面检查已选课堂；确认原请求不会再完成后，输入“已核对”解除。解除意味着后续可以再次提交。记录损坏或新旧版本同时存在两笔记录时停止，不能靠随意清空浏览器存储解决。

### 不自动退课，也不默默替换选择

检查同名、本学期、系统返回的课程方案。教师能唯一确定方案和课堂时可以继续；仍有多个匹配课堂或方案时，显示候选并等待你限定。不会因为只有一个班还有余量就擅自选那个班。

在返回的同名课程方案中发现已经选了其他教师/课堂，会阻止该目标的提交，不会先退后选。程序没有退课接口，也没有权限、验证码或时间限制绕过逻辑。

**只能核对这组接口实际返回的课程和课堂，不保证覆盖学校另外的“全部已选课程”系统。** 课表冲突、学分限制、培养方案资格、校区、上课时间等没有新增自动判断；由你核对，并由服务器作最终判定。

### 暂停、账号与跨标签

暂停会阻止后续请求，但不把已经发出去的选课当作取消。正在等待的提交仍可能成功；超时的 AbortController 也不提供服务器事务回滚。

同源运行标签通过 Web Locks 互斥。本版使用统一锁，不因课程或学期不同而分别运行；同时尝试取得原脚本的锁。锁冲突时提示你先暂停另一个页面，不在后台自动接管。缺少锁能力时不发请求。

这不协调另一个浏览器配置文件、其他设备、不使用这些锁的旧工具或手动操作。自动模式下不要同时手动提交，也不要切换账号。原脚本没有提供可靠的当前学号/身份查询接口，本版也没有擅自猜测，**不会自动验证当前登录学号**。换账号前先停止并处理待确认记录。

### 请求频率

默认每轮结束后等 3 秒，同一页面请求最小间隔 500 毫秒，明确业务拒绝后的同课堂重试间隔 15 秒。请求队列串行执行，预览和自动模式共用队列。网络或限流错误指数退避，默认上限 60 秒。

登录失效、无法解释的字段结构变化、安全检查失败会停止。其他业务拒绝按冷却间隔处理；不会把未知内容当成成功。后台标签降频、休眠、登出都会影响运行，不能承诺抢到课程。请遵守学校的使用要求。

成功的首个列表响应在 `count` 缺失或为 `0`，且 `data` 被省略、为 `null`、空字符串或空对象时，按“当前列表为空”处理。自动模式会等待正常扫描间隔后继续轮询，不会因为课程尚未开放而停止。正数 `count` 对应空值、非空的非数组 `data` 或后续页返回空值仍视为无法安全解释的响应。

### 分页处理的变化

原脚本对 `count=0` 直接认为本次已经返回全部数据。本版把“count=0 且 data 非空”作为总数未知：短页可结束；满页继续检查后续页，后续页返回空值、重复页、总数变化、提前结束或超过上限都会停止，不使用可能截断的候选列表。

如果某个真实接口明确是“不分页、返回全部课堂、count 恒为 0”，且返回条数达到页大小，本版可能因重复页停止。这是有意保守的行为，需要拿真实只读响应确认后，在适配层单独处理；不要直接删除所有分页校验。

## 结构

```text
src/
  core.js       错误类型、响应检查、字符串规范化等基础函数
  config.js     默认值、配置校验、目标标识、存储键与锁名
  domain.js     课程/详情校验、课堂合并、教师与编号匹配
  api.js        唯一知道接口路径、HTTP 方法、参数和分页约定的适配层
  storage.js    配置和待确认日志，读写校验、旧版本兼容
  engine.js     扫描、判断、提交、确认和退避；不操作 DOM
  session.js    跨标签锁、一次预览/自动循环、暂停和生命周期
  ui.js         表单、候选展示、按钮和日志；不知道接口路径
  main.js       启动与依赖组装
scripts/
  build.cjs     无第三方依赖的简单 CommonJS 模块打包器
  verify.sh     测试、构建和语法检查
  inspect.sh    查看提交请求相关代码，便于人工审查
test/
  *.test.cjs    Node.js 内置测试运行器的离线测试
  browser-smoke.py  可选的 Chromium DOM 冒烟测试
```

配置和领域对象在构建后冻结；每次启动创建新的引擎，不沿用上一轮已完成目标。内部任务标识包含课程、教师和编号限定，而不是仅用课程名当索引。运行中不能编辑目标；有待确认记录时也锁住编辑，优先处理原记录。

这是结构分层，不是把源代码压成更少行。安装仍是一个 `.user.js`；不引入 React、Vue、TypeScript 编译链、npm 依赖或远程 CDN。

## 开发与测试

开发/构建环境使用 Node.js 22 或更新版本。没有 npm 依赖，因此不需要先执行 npm install。

```sh
npm test
npm run build
npm run check
# 或：sh scripts/verify.sh
```

本次实测：55 项 Node.js 离线测试通过；9 项 Chromium DOM 检查通过；生成脚本通过语法检查。

`test-results.tap` 和 `browser-test-results.json` 是实际测试输出，`preview.png` 是模拟页面截图。Node 测试覆盖教师精确匹配、跨学期、重复方案、已选课堂、同教师多课堂、满额、只读模式、未知提交结果、刷新后的待确认快照、旧记录、持久化失败、冷却、队列串行、空列表持续轮询、分页、暂停、锁冲突等情况。

浏览器检查在 about:blank 页面进行，向启动函数注入内存版 fetch、存储和锁夹具，检查真实 DOM 中的填写、候选限定、按钮、确认、待确认显示等交互。**这不是学校页面或实际用户脚本管理器的实测，也不是原生跨标签锁的集成验证。** 当前执行环境禁止浏览器导航到外部和本地网址，因此未完成这些集成验证。程序没有登录你的账号，也没有执行真实选课。

可选重跑 DOM 检查需要 Python 的 playwright 包以及 Chromium。默认在 PATH 中找浏览器，也可以设置环境变量 CHROMIUM_EXECUTABLE。测试夹具仅在内存中把启动对象替换为模拟对象，不修改分发脚本的站点限制。

```sh
python test/browser-smoke.py
```
